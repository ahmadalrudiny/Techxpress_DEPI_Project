TechXpress - E-Commerce Platform for Electronics

A full-stack e-commerce platform developed as a collaborative team project during the Digital Egypt Pioneers Initiative (DEPI).
The system is designed to provide an organized platform for managing core e-commerce operations, including product catalogs, customer shopping carts, secure online payments, and administrative management.

Project Overview

The main goal of this project is to build a practical and scalable e-commerce platform while applying modern software development practices, N-Tier clean architecture principles, Entity Framework Core, database management, and collaborative Git/GitHub workflows.

Main Features

Customer Management & Authentication: Secure registration, login, and role-based authorization powered by ASP.NET Identity.
Product Catalog & Browsing: Browse a wide range of electronic products with detailed descriptions, images, and stock levels.
Search and Filtering: Filter products by categories, price ranges, and keyword searches.
Shopping Cart Management: Add, update, and remove items with real-time total calculations.
Secure Checkout & Payment: Integrated with Stripe API for secure online credit card processing.
Order History & Management: View past orders, track order status, and manage purchase history.
Admin Dashboard & Reports: Centralized administrative panel for managing products, categories, and customer orders.
Interactive DataTables: High-performance data tables featuring search, sorting, and pagination.
Responsive User Interface: Fully responsive design optimized for all devices using Bootstrap 5.
